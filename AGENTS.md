## Agent skills

### Issue tracker

Issues are cards on the Hermes Kanban board (`hermes kanban`, default board DB `~/.hermes/kanban.db`). See `docs/agents/issue-tracker.md`.

### Triage labels

Kanban has no labels: the five triage roles map to card statuses and block kinds. See `docs/agents/triage-labels.md`.
